# Computer Vision Projects

A collection of real-time computer vision applications built using Python, OpenCV, and MediaPipe on Linux.

## Features

- Hand gesture recognition
- Volume control using gestures
- Virtual mouse control
- Real-time webcam processing
- MediaPipe landmark tracking
- Audio and device interaction
- Lightweight and CPU-friendly implementations

---

# Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- SciPy
- PyAutoGUI
- PulseAudio
- Matplotlib

# Installation

## Clone Repository

```bash
git clone <your-repo-url>
cd computer-vision-project
```

## Create Virtual Environment

### Linux

```bash
python3 -m venv venv
source venv/bin/activate
```
